Αποτελέσματα

Συμπλήρωσε τα στοιχεία και πάτησε υπολογισμό για να δεις τη διαδρομή, ταχύτητα, καύσιμα, κινδύνους και ETA.

Χάρτης διαδρομής

Πώς να επεξεργαστείς τη διαδρομή:
• Σύρε ένα teal (ενδιάμεσο) waypoint → το μετακινείς
• Διπλό κλικ σε κενό σημείο του χάρτη → προσθέτεις νέο waypoint εκεί
• Δεξί κλικ σε ένα teal waypoint → το διαγράφεις
• Σύρε σε κενό σημείο → μετακίνηση χάρτη · scroll/pinch → zoom
Τα λιμάνια αρχής/τέλους (πορτοκαλί) δεν μετακινούνται/διαγράφονται — άλλαξέ τα από τα dropdown στη φόρμα. Απόσταση/ταχύτητα/καύσιμα ενημερώνονται αυτόματα σε κάθε αλλαγή.
Πραγματικός παγκόσμιος χάρτης (Natural Earth 110m). Κίτρινες κουκκίδες = φάροι, κόκκινοι κύκλοι = ζώνες TSS (OpenSeaMap).
Live δεδομένα: καιρός + ρεύμα (Open-Meteo Marine/Forecast API), βάθος θαλάσσης (Open Topo Data / GEBCO), και φάροι/TSS ζώνες (OpenSeaMap μέσω Overpass API) — όλα δωρεάν, χωρίς key. Το OpenSeaMap είναι crowd-sourced (σαν Wikipedia), όχι επίσημο ENC — καλό για αναφορά/εκπαίδευση, όχι για πραγματική ναυσιπλοΐα. Οι κίνδυνοι/ασφάλεια (πειρατεία, MSI/NAVTEX) παραμένουν curated/στατικά — δεν υπάρχει απλό δωρεάν live API γι' αυτά. Σε πραγματική εφαρμογή θα χρειαζόταν συνδρομή σε υπηρεσία όπως UKMTO/MSCHOA reporting, ή εμπορικό feed (π.χ. Dryad Global, Ambrey).
